Upload to Steam

Open Steam upload ↗
  1. Choose a file

    Sign in to Steam in your browser. On the upload page, pick an exported file and give it a title.

  2. Run the command

    After choosing the file, press F12 and open the Console tab. Paste the command below and press Enter.

  3. Publish the artwork

    Set visibility to Public, confirm that you created the artwork and save. Repeat these steps for the right strip.

  4. Set up the showcase

    Go to Edit Profile → Featured Showcase. 

$J('#image_width').val('1000');$J('#image_height').val('1');

The command sets the form dimensions for long artwork. The artwork picker may show the result as a thin strip.
